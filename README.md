# Cotizador de Prestamos en Vue.js

Aplicacion web para cotizar prestamos en tiempo real, calculando el total a pagar y las cuotas mensuales segun el monto solicitado y el plazo seleccionado.

## Caracteristicas

- Calculo automatico del total a pagar e intereses segun la cantidad.
- Seleccion de monto mediante control deslizante y botones de incremento y decremento.
- Seleccion de plazo en 6, 12 y 24 meses.
- Calculo y desglose de la mensualidad fija.
- Formato de moneda en USD.
- Diseno responsivo para moviles y escritorio.

## Tecnologias

- Vue.js 3 (Composition API y script setup)
- Vite
- Tailwind CSS
- JavaScript

## Pasos para ejecutar el proyecto

1. Instalar dependencias:

```bash
npm install
```

2. Iniciar el entorno de desarrollo:

```bash
npm run dev
```

3. Abrir en el navegador la direccion indicada en la terminal (por ejemplo `http://localhost:5173/`).

## Compilacion para produccion

```bash
npm run build
```
